# Post-Processing-Magic 0.28.0

- Eigener vergrößerbarer Ergebnis-Reiter mit begrenzter CSV-/XLSX-Tabelle, Blattwahl, Filter und Sortierung nach Text/Zahl/ISO-Zeit vor Paginierung.
- CSV: maximal 1 MiB / 2.000 Datenzeilen; XLSX: maximal 64 MiB Paket / 2.000 Datenzeilen, 64 Spalten. XLSX-Paket-/XML-Budgets, keine Formelauswertung, keine externen Verbindungen; Formelzellen zeigen ausschließlich gespeicherte Werte. Excel-Datumsserien bleiben roh. Keine Gesamtdateisuche oder globale Timeline. Zeitzonenlose und zonierte ISO-Werte werden getrennt gruppiert; keine Zeitzone wird erfunden.
- Lokale Viewer auf bewussten angemeldeten Nutzerklick: Timeline Explorer für CSV, EZViewer für XLSX. Programmdateien separat bereitstellen und Pfade unter Einstellungen → Allgemein speichern; gemeinsame Toolverwaltung/JSON-Transfer. Datei-Aufruf mit einem absoluten Dateipfad für synthetisch geprüfte Version 2026.5.0 freigegeben und an EXE-/DLL-Fingerprints gebunden; andere Builds zunächst ungeprüft. Viewer laufen auf dem Server mit dessen Rechten, außerhalb der internen Vorschau; keine Sandbox.
- Sieben pfadgebundene Inventargruppen aus dem entpackten Eingang vor Befehlen. Bestandsaufträge werden nicht nachgescannt. Dateianwesenheit ist kein Inhalts- oder Aktivitätsbefund.
- HTML-Berichte einklappbar, Druckinhalt unabhängig vom Klappzustand vollständig. Hohe Komprimierung als abwählbare Browser-Vorauswahl für neue Aufträge; alte Snapshots/API-Vorgaben unverändert.

Windows-ZIP vollständig entpacken, EXE starten und UAC bestätigen. README, Lizenz und EXE-Prüfsumme liegen bei. Bestehende Instanzen vor einem selbst gewählten Wechsel bewusst geordnet beenden. Kein automatischer Analyse- oder Viewerstart durch Import/Speichern.
