# Post-Processing-Magic 0.29.0

- Getrennte CSV-/XLSX-Untertabs mit formatgebundenen Dateilisten. Formatwechsel setzt Datei, Blatt, Filter, Sortierung und Seite zurück; veraltete Antworten werden verworfen.
- Sortieren direkt per Spaltenüberschrift: aufsteigend, erneut absteigend, mit Pfeil, aria-sort und Tastaturbedienung/Fokuserhalt. Keine Sortier-Choicebox.
- Konservative Typhinweise aus dem gesamten begrenzt eingelesenen Fenster: Text, Zahl oder eindeutige ISO-Zeit. Führende Null, mehrdeutige Werte und gemischte Angaben ohne/mit Zeitzone bleiben Text. Optionaler Typwechsel direkt im Header. Originalwerte bleiben unverändert; Filter/Sortierung weiterhin vor Pagination innerhalb der Vorschaugrenzen.
- Zwei zusätzliche pfadgebundene Inventargruppen: Windows-Suchindex (Windows.edb im bekannten Search-Pfad) und Windows-Aktivitätsdatenbank (ActivitiesCache.db im bekannten Benutzer-/Kontopfad). Classifier 3; keine Inhaltsanalyse, Aktivitätsbefunde oder Nachinventur alter Aufträge.

Windows-ZIP vollständig entpacken, EXE starten und UAC bestätigen. README, Lizenz und EXE-Prüfsumme liegen bei. Bestehende Pakete bleiben unverändert. Noch keine neuen Nachtmeilensteine in dieser Version.
