# Post-Processing-Magic 0.25.2 – Desktop-Hotfix

- Behebt die fehlende SSL-Policydatei bei lokal verwendeten Python-Distributionen. Das Desktopfenster kann den laufenden Server wieder abfragen und zeigt Status, Worker, Adresse und Token an. Zertifikatsprüfung bleibt aktiv.
- Beenden-Button erhält dauerhaft seine volle Höhe. Der Logbereich schrumpft bei kleineren Fenstern; der Hinweistext kann umbrechen.
- Technische Diagnose für Fehler der Desktop-Verbindung ergänzt.
- Gemeinsame Konfiguration und beide Arbeitsbereiche aus 0.25.1 enthalten. Konfigurationstest vom Nutzer bestätigt.

Windows-ZIP vollständig entpacken. Alte Instanz geordnet beenden, neue EXE starten und denselben Datenordner verwenden. Windows-UAC bestätigen.

Lokale Vorprüfung der Korrekturen: 148 Tests/Ruff, gepacktes Desktopfenster und drei Fenstergrößen geprüft. Dieser Release wird zusätzlich durch GitHub Actions gebaut und mit den EXE-Testgruppen geprüft. Nur synthetische Testdaten; keine neuen Analyseadapter.
