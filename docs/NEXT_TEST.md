# Dokumentation ansehen – 0.41.0

0.40 ist erfolgreich abgenommen. 0.41 ergänzt ausschließlich englische Codedokumentation und ein lokales HTML-Code-Wiki; keine neue Funktionsabnahme von 0.40 verlangen.

## Änderungen

Englische Docstrings und Kommentare, statisches Offline-Code-Wiki, aktualisierte README/Architektur und Dokumentation im Release-ZIP. Kein Refactoring, keine Sicherheitskorrektur oder Änderung bestehender Aufträge/Toolprofile.

## Optional ansehen

1. Windows-ZIP von GitHub herunterladen und vollständig in einen eigenen Versionsordner entpacken.
2. docs/code-wiki/index.html doppelklicken. Das Wiki öffnet direkt im Browser; dafür ist kein App-Server und kein Access Token erforderlich.
3. Architektur, Module, API-/Verarbeitungsabläufe und Entwicklung öffnen. Interne Links und lokale Ressourcen sollen offline funktionieren.
4. README sowie die beschriebenen Grenzen prüfen. Das Wiki beschreibt die vorhandene Implementierung und ist kein Sicherheitsgutachten.

Feedback zur Dokumentation mit Seitenname oder Überschrift direkt im PM-Chat melden. Die bestehende 0.40-Arbeitsinstanz bleibt erhalten. Für diese Dokumentationsprüfung ist keine neue Nutzer-Testinstanz gestartet und kein neuer Token erzeugt. Ein späterer bewusster EXE-Start verwendet wie bisher UAC und einen eigenen aktuellen Sitzungstoken.
